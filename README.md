The exercise solutions are grouped in `LAB 1` through `LAB 10`. Each question has its own Java source file named `Q1_...java` to `Q5_...java`. Lab 11 is the library mini-project in its own folder.

## Running an exercise

Use JDK 17 or newer. Open a terminal in the relevant lab folder, compile one file, then run its public class. For example:

```text
javac Q1_CarShowroom.java
java Q1_CarShowroom
```

Some programs ask for console input or create a small data file in the current folder. The Lab 11 run instructions are in [LAB 11/README.md](LAB%2011/README.md).

The examples use small class data and brief comments so they are easy to discuss during a lab viva. Update any sample names, marks or amounts to match your own class instructions before submission.
